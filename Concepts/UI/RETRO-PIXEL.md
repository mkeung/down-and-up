# Retro-pixel direction

Retro pixel is the selected visual direction for Down & Up. The baseline is [03-retro-pixel.png](03-retro-pixel.png): stepped panel edges, legible pixel numerals, neutral keycaps, and pixel-art grid/paw navigation. The icon is now a compact pixel portrait of the existing Cerberus character.

The mobile UI now implements shared stepped controls, pixel numerals, framed notes, and custom grid/paw tabs. The native icon uses official master 10. See [visual direction](../../docs/visual-direction.md) for implementation and remaining device checks. Palette and custom button/tab treatments below remain alternatives, not final choices.

Color belongs to the overall surfaces and chrome, never to the numeric scale. All ten keys retain one neutral color family and identical art. Selected 7 has a neutral double frame and checkmark. The newer boards also show the planned top-right cloud/check data-status control from [`docs/completed/data-status-icon.md`](../../docs/completed/data-status-icon.md); the earlier five studies predate that decision and still show bottom sync text. Status color describes storage only. Custom tabs retain the existing Rate and Pawsitive labels and equal touch areas.

## Icon

[Official retro-pixel icon](../../OfficialAssets/10-cerberus-retro-pixel-icon.png). `scripts/icons.mjs` prepares the 1024×1024 native asset from this master. The earlier icon studies 09b and 09c live in `Concepts/` for reference. [Retro-pixel character 01e](../../OfficialAssets/01e-cerberus-retro-pixel-character.png) redraws the full-body 01c character in the same style as official icon 10.

## Exact prompts

All assets use the built-in image generation tool. Input paths below are relative to the repository root.

### 10-cerberus-retro-pixel-icon.png

Destination: `OfficialAssets/10-cerberus-retro-pixel-icon.png`.

References: `Concepts/09b-cerberus-app-icon-front-paws.png`, `Concepts/01d-cerberus-pixel-low-fidelity.png`.

```text
Use case: style-transfer.
Asset type: final mobile APP ICON, square 1024x1024 opaque PNG.
Edit target image 1: existing Cerberus app icon with three heads, three tails, two small front paws and hidden legs. Image 2: low-fidelity standing pixel Cerberus for pixel technique reference only, NOT its full-body pose.
Redraw image 1 as extremely crisp chunky RETRO PIXEL ART, as if made on a 64x64 pixel canvas enlarged using exact sharp square pixels. Keep the connected compact three-head PORTRAIT composition, little golden/cream chest and exactly TWO small brown/gray TABBY FRONT PAWS at the bottom, with all legs hidden. Exactly THREE recognizable heads: small orange Pomeranian left, larger golden/tan dog with dark brown muzzle and upright ears middle, gray-brown striped tabby cat right. Exactly THREE separated tails behind the heads: cream/orange curled Pom plume on left, golden swept dog tail middle, thick dark striped cat tail right. No collars.
Limit to about 12 flat opaque colors including dark outline, 2–3 fur tones per pet, simple black pixel eyes and noses, a few bold tabby bands. All outlines consist of obvious chunky square steps. Faces use minimal small pixel marks and quietly attentive expressions. NO smooth vector curves, antialiasing, gradients, detailed fur, dithering, tiny noisy texture, glossy eyes, 3D, glow or drop shadows.
Background solid warm ivory, edge to edge, completely opaque. Character occupies central ~76 percent of canvas with at least 12 percent safe margin on all sides. All heads, ears, paws and tails fit comfortably inside the square and remain readable at 48px icon size. No rendered rounded square frame, borders, text, numbers, letters, UI, scenery, props, badges, hearts or watermark. Output ONLY the single finished icon image, not a presentation board.
```

### 06-retro-mint-cartridge.png

Destination: `Concepts/UI/06-retro-mint-cartridge.png`.

References: `Concepts/UI/03-retro-pixel.png`, `Concepts/01d-cerberus-pixel-low-fidelity.png`.

```text
Use case: ui-mockup.
Primary request: new youth-oriented RETRO PIXEL UI exploration for Down & Up, experimenting with colored app surfaces and custom pixel-art keycaps and tabs. This is a new high-fidelity concept board, not a game and not an implementation.
Input image 1: existing retro-pixel UI for flow and typography reference only. Reimagine its color palette and button/tab art according to the direction below. Input image 2: Cerberus sprite identity reference only.
Composition: landscape 1536x1024 style presentation, TWO very large front-facing upright phone mockups side by side, flat 2D screens, no perspective, hands, photo setting, props. Outside the phones only small exact title "Down & Up" and direction name. No slogans or other text outside screens.
Both screens have tiny normal OS status bar, top-right small GREEN PIXEL CLOUD WITH CHECKMARK data-status/settings icon with generous touch padding, then same date selector: left pixel chevron, centered "Today" with "Sun, Oct 11" below, disabled dim right chevron. Green cloud icon is ONLY a data-status color exception, unrelated to selected value. No additional header text.
LEFT screen Rate: EXACT 3-column keypad rows "1 2 3" / "4 5 6" / "7 8 9" and a fourth row ONLY "10" CENTERED BELOW 8. Each key at least 72x72 logical points, square-ish with identical custom pixel-art frames. All TEN key surfaces MUST have ONE IDENTICAL NEUTRAL gray/stone color, no tinted keycaps, no different art by value. Large clean readable ivory or charcoal pixel numerals. Selected key 7 uses thick DOUBLE NEUTRAL outline plus a small CHECKMARK and modest neutral fill shift, NEVER a colorful outline. Main screen contains only date controls, data-status icon, ten number keys and bottom navigation; no mascot, decoration, labels, prompts, save button or bottom sync text.
RIGHT screen Pawsitive: same date and top-right cloud status icon. Large note panel with "Note" and "Walked home. Found a new song." in clean readable text, surrounded by custom pixel-art frame. Below, ONE quiet small decorative pixel Cerberus sprite, three heads on one shared golden body: orange Pom on LEFT, larger golden dog with dark muzzle in MIDDLE, brown-gray tabby cat on RIGHT. Exactly three separated tails, no collars. Natural coat colors. Sprite is a static brand decoration, never gameplay or reacting to values.
BOTH screens bottom navigation has ONLY TWO equal-width CUSTOM PIXEL ART TABS. Labels EXACT "Rate" and "Pawsitive" (P-a-w-s-i-t-i-v-e). Rate has nine-square grid icon. Pawsitive has pixel paw icon. Left Rate tab active; right Pawsitive tab active. Selected tab indicated with neutral ivory outline/underline as well as shape, not color alone. Custom art fits generous touch targets without sacrificing labels. Tabs sit above OS home bar.
Style: crisp square pixel clusters, handcrafted 16-bit UI panel art, controlled shadows, readable pixel typography and plain readable note body. Mature teen/young-adult appeal. Palette coloration is GLOBAL app chrome/background, never encoding good/bad numbers. No gradients, emoji on keys, emotions/mood/wellness wording, extra tabs, History/Settings labels, rewards, XP, coins, badges, streaks, game scenery, controls for recordings/audio, account IDs, save/clear buttons, watermarks or unsolicited copy. The screen elements must remain functional and uncluttered.
Direction name (outside phones): "Mint cartridge".
Global palette: muted mint/sage console-like screen surround, creamy ivory typography areas, charcoal ink. ALL KEYS warm light stone-gray with dark numbers and a charcoal selection frame. Custom art: chunky cartridge-inspired double-stepped keycap rims, tiny identical corner rivets, crisp 2-pixel lower shadows. Date panel a restrained beveled cartridge label. Bottom tabs two low raised stepped tiles with bespoke square-grid and pixel paw symbols; a tiny notch in the active tab frame. Note panel cartridge-label frame. No physical console controls or brand references.
```
